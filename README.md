# ZZZ-TextData

## 项目声明

* 所有内容均来自 [miHoYo](https://www.mihoyo.com/) 旗下的[绝区零](https://zzz.mihoyo.com/main/)游戏当前公开版本以及[绳网情报站](https://baike.mihoyo.com/zzz/wiki/)

## 项目介绍

* 提供绝区零游戏(v2.6.0)内的部分相关文本

## 目前所提供的内容

* MessageConfig-Message--(所有对话？)--(自行整理使用)
* PartnerConfig--代理人相关
* AvatarTalentConfig--代理人天赋相关
* InterKnotConfig--绳网内所有帖子
* MonsterCardConfig--法厄同图鉴(怪物图鉴描述)
* NewsConfig--都市快报
* SpecialEventConfig--空洞见闻-特殊区域记录
* ErosionConfig--空洞见闻-侵蚀症状

## 暂时不提供的内容

* TrustLVConfig-代理人好感相关(因为部分原因，无2.6版本)
* 对于剧情文本，因内容过多，暂不整理(因结构摸索较为耗时)
* 对于特殊或非常规文本，暂不整理(视具体情况提取)

## issues

* 部分文件内容可能出现null情况，有可能是正常现象
* 如果文本有大问题，请开issues告知，我会尝试修复(有时新版本文件结构可能有所变动导致提取时出现null)
* 如果你有其他需要的文本内容，请开issues告诉我(视具体情况提取)
